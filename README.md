# MubashLume

Shopify Growth Strategy portfolio, restored from the saved stable AppDeploy version.

## Run locally
```bash
npm install
npm run dev
```

## Routes
- / — About
- /full-reviews — illustrative project examples and indicative fees; these are not customer testimonials or claims of completed client work
- /full-portfolio — curated public storefront directory
- /contact — project enquiry

## Required image assets
The app references three original binary images that must be placed in `public/resources/`:
- `mubashlume-profile.png`
- `mubashlume-sales-banner.png`
- `review-portraits.png`

The source code is transferred. The image assets still need a separate transfer before the Lovable import will be visually complete.
